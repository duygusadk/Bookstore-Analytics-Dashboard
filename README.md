# Bookstore-Analytics-Dashboard

## Overview

This project is an interactive Power BI report developed as part of a university coursework assignment. It uses a bookstore database consisting of 13 tables to explore book information, editions, ratings, and sales.

<img width="650" height="400" alt="image" src="https://github.com/user-attachments/assets/5d2c1aed-8582-444f-95ac-3fe100784623" />

The project focuses on data modeling, interactive visualizations, and the use of Power BI features to present information in a clear and structured way.

## Report Pages

### 1. Books Information
- Displays book details, including titles, authors, genres, editions, awards, and ratings.
- Highlights books that received awards in consecutive years.
- Identifies the top 5 books by average rating, using price as a tie-breaker.
- Presents the top 3 authors based on the ratings of their books.
- Uses tooltip pages to display additional information about authors and their books.
  
  <img width="700" height="300" alt="image" src="https://github.com/user-attachments/assets/0ce7c61a-c428-428e-9b82-d3a0bacdd73e" />


### 2. Editions Information
- Presents publishers and their editions in a hierarchical view.
- Displays book prices, publication dates, cover formats, and page counts.
- Highlights editions with fewer than 150 pages.
- Identifies the publication dates of the 10 most expensive books and provides additional information about publication dates and author rankings.

  <img width="600" height="350" alt="image" src="https://github.com/user-attachments/assets/7bb24e93-63fc-4f5c-922b-705c8523c6c9" />


### 3. Sales Information
- Displays order details, including order numbers, item quantities, and total prices after discounts.
- Identifies the items included in the order with the highest discount.
- Includes a drill-through page for information about books within an order.

## Power BI Features

- Data modeling and relationship management
- DAX measures and calculated metrics
- Power Query for data preparation
- Visualizations and slicers
- Report tooltips
- Drill-through navigation
- Bookmarks and interactive buttons

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Relational databases

## Purpose

The purpose of this project was to practice data modeling, data analysis, and interactive report development in Power BI while meeting a set of defined analytical and visualization requirements.
